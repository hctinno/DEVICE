## 공개 게시 범위

엑셀·JSON·CSV·SQLite와 코드 링크 목록은 조사 산출물의 바이트를 유지했다. 보고서에는 이 공개 게시 범위 안내를 추가했다. 제조사/모델과 출처 URL, 자체 작성한 판정·근거·미확보 상태, 검색어, 링크 접근 결과, 원본 로그 해시를 게시한다.

공개 Git 저장소이므로 검색 도구가 반환한 제3자 웹페이지 전문, 제조사 문서/실행파일 사본, 내려받은 외부 코드 전체는 게시하지 않았다. 실제 검색 로그 999개는 **검색어·발견 URL·도구 오류 플래그·원본 해시/크기**로 정리했다. 검색색인 확인과 원문 열람 여부는 모델별 결과의 `access`에 남아 있다. 원문은 해당 URL과 라이선스에 따라 확보한다.

따라서 공개 ZIP은 이전 클라우드 원시 응답 포함 ZIP과 바이트가 다른 공개 게시본이다. 원래 ZIP의 SHA-256과 각 항목 대응은 `provenance/publication_ledger.json`에 기록했다. 자료를 사용자에게 다시 첨부받을 필요 없이 Git으로 인수한다.

이 ZIP은 `labflow import-package`용 규격 원문 배치 형식이 아니다. 별도 조사 스냅샷으로 읽고, 현재 총괄의 자료 카탈로그에 출처 관계를 추가한다. 원래 `data/equipment.sqlite3`나 현재 개발 DB를 이 SQLite로 교체하지 않는다.

## 인수 검증

저장소 루트에서 다음을 실행한다. 표준 Python 라이브러리만 사용하며 장비에 접속하지 않는다.

```bash
python research/equipment-control-2026-10-24/verify_bundle.py
```

파일 해시·ZIP 내용·SQLite 무결성·3,137항목/6,470등록행 대응을 검증한다. `.gitattributes`가 Windows 체크아웃에서도 스냅샷의 줄바꿈 바이트를 보존한다. 장비 주소·설치 옵션·펌웨어·현장 컨트롤러는 미확정이며 실장비 시험은 미실행이다.

`provenance/research_scripts/`는 당시 조사 생성 스크립트의 보관본이다. 당시 클라우드 경로를 포함할 수 있어 다른 PC에서 그대로 실행하지 않는다. 현재 인수 검증에는 위의 경로 독립적인 검증기를 사용한다.
