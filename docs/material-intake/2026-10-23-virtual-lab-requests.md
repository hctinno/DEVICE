# 가상 시험소 개발 자료 요청 — P01 협의 기록

작성일: 2026-10-23 (Asia/Seoul). 요청 ID: **DEV-VLAB-20261023-001**.

사용자가 개발총괄과 메인(P01)의 직접 소통을 위임했다. 개발총괄은 확인한 `메인 에이전트로 대기` 채팅에 아래 요청과 현재 개발 상태를 실제 메시지로 전달했고, **P01의 접수·현황 회신을 받았다**. 수집자 개별 채팅에는 요청하지 않았다. 개발용 상세 색인은 P01이 준비하기로 했으며, 신규 수집 배정·전체 원문 인수·기술 검토 완료를 뜻하지 않는다.

## 개발 목적

기존 접수·분석 계약과 영속 작업 기반을 사용해 가상 스마트폰, 계측기, RF 연결 경로와 장애 시나리오에서 AI 하네스를 검증한다. 먼저 전도 출력 한 흐름을 대상으로 한다. 특정 실장비 모델·옵션·펌웨어는 아직 선정·검증하지 않았으며, 수집 결과의 실제 근거를 보고 첫 지원 프로필을 결정한다.

메인에 요청한 최초 현황은 인수 가능한 배치·고정 snapshot·receipt 경로, 진행 중인 자료, 막힌 항목과 추가 입력이다. 이전 공개 5개 배치는 개발 쪽에서 인수했지만 이후 수집 배치를 자동 인수한 것으로 처리하지 않는다.

## 요청한 반환 형식과 역할

- 기존 확보물부터 경로·문서 ID·판본·해시·권리·인수 상태를 매핑한다. 각 요청의 부족분은 미확보·접근 제한·현장 입력 필요 등 실제 상태로 남긴다.
- 실측·합성·매뉴얼 예제·성적서 표를 구분한다. 성적서의 수치표를 원시 계측 파일로 취급하지 않는다.
- 기존 진행 작업은 유지하고 부족분만 P01이 작은 후속 수집으로 배정한다. 전 모델 재수집이나 기존 원문 재다운로드를 요구하지 않는다.
- 기술 적용성 판단·방법 승인·계산·코드·시뮬레이터 구현은 개발총괄이 맡는다. 수집자에게 개발 결정을 넘기지 않는다.
- 이번 요청은 자료 현황·원문 위치·공개 근거에 관한 것이다. 신규 실측, 시험장 네트워크 검색, 단말 조작, 외부 연락 또는 비공개 패키지 취득을 위임하지 않는다.

회신은 메인 채팅 또는 P01 인수 기록에서 확인한다. 개발총괄은 자료별 인수 결과와 남은 공백을 동일 요청 ID로 회신한다. 고정 자료의 실제 복사·해시 검증·기술 검토가 완료된 후 각각의 상태를 갱신한다.
