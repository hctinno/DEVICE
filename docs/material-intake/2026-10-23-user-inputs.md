# 사용자가 직접 준비할 자료

갱신일: 2026-10-24, Asia/Seoul. 사용자가 제공한 SM-A176U 자료를 인수했고 현재 개발 기준은 **Un-licensed 전체 장비/시험 흐름**이다. 공개 공식 자료는 계속 P01이 담당한다.

**지금 가상환경과 기능 개발을 위해 사용자가 새로 준비할 필수 자료는 없다.** 제공 폴더에 제품/변형·안테나·출력 설정, 의뢰·시험기록·장비표·셋업 사진·계산 파일·발행 성적서가 있다. Un-licensed 암호화 Excel 14개도 사본에서 해제해 분석했다. 원시데이터는 개발의 선행조건이 아니며 Licensed 추가 암호/최종 raw 확인은 사용자 결정에 따라 보류한다. 전체 시험소의 업무·물리 작업 무인화 목표는 유지한다.

## 실장비 연결 전에 확인할 최소 자료 — 첫 제품 1대와 시험 구성 1개

기존 파일이 있으면 접근 가능한 폴더 위치를 알려 주는 것으로 시작한다. 새 설명서나 정리표를 작성할 필요는 없다. 없는 자료는 미보유로 표시하고, 개발총괄이 필요한 세부 항목을 확인한다.

| 묶음 | 사용자가 제공할 최소 자료 | 공개 자료만으로 해결되지 않는 이유 / 사용 시점 |
|---|---|---|
| U01. 실제 시험용 스마트폰과 제조사 시험도구 | 제품 사양·안테나·출력/tune-up·과거 HW/FW 자료는 확보했다. 실제 연결할 시료의 현재 FW/HCF와 호환되는 RF 시험도구 버전·시작/중지/설정 읽기/오류·복구 인터페이스만 해당 단계에서 확인한다. 기존 도구 패키지나 사용법 위치가 있으면 인수한다. | HCF/BAT 배포 파일과 출력 목표표만으로 RF 제어 API가 확정되지 않는다. 실제 DUT 어댑터와 시험모드 검증 전에 필요하다. 가상 개발을 기다리게 하지 않는다. |
| U02. 실제 사용할 계측 구성과 교정 자료 | 기존 6,470행 자산 대장, 해당 보고서 장비표·교정일/셋업은 확보했다. 첫 실제 bench를 정할 때만 현재 옵션/FW, 연결 포트·손실/보정 경로와 해당 시점 교정 근거를 확인한다. 전체 자산표를 다시 만들 필요는 없다. | 과거 보고서의 자산과 교정일은 현재 연결/교정 상태와 별개다. 실제 연결 및 보정 계산 검증 전에 필요한 입력이다. 가상 catalog는 보고서 N1911A/N1921A 등을 각각 보존한다. |
| U03. 기존 실제 시험의 독립 수치 검증 | 제공 Un-licensed 의뢰/기록·계산 워크북·성적서를 먼저 사용한다. 최종 XLSX의 저장 수식/캐시와 보고값을 대조했으며 일부 판본 선택·단위 문제는 별도 기록했다. 추가 계측기 원시 trace/세션 로그는 추후 독립 비교에 필요한 항목만 요청한다. | 기능·가상환경 개발에는 추가 raw가 없어도 된다. 계측 정확도·보고 수치·가상/실측 차이의 독립 검증에서는 원 측정 조건과 추적 자료가 필요하다. 지금 새 측정이나 Licensed 암호 제공을 요구하지 않는다. |
| U04. 회사가 보유한 제한 원문·소프트웨어의 이용 위치 | 유료 규격 원문, 비공개 OEM 매뉴얼/도구를 이미 보유했다면 허용된 파일 경로나 열람 방법 및 사용 조건. 정확한 미확보 문서명·판본은 P01의 조사 결과로 좁힌다 | 공개 요약은 허가된 원문을 대체하지 않는다. 지금 일괄 구매하거나 비밀번호/라이선스 키를 전달할 필요는 없다. 필요한 원문 검토·해당 도구 연동 단계에 맞춰 확보한다. |

U01과 U02는 첫 실물 연동 대상을 정한 뒤 확인할 입력이며 현재 가상 개발의 대기 조건이 아니다. U03/U04도 해당 검증·연동 범위가 구체화되면 확보 자료부터 재사용한다. 제한 원문과 실제 고객 자료는 공개 Git에 넣지 않고 허용된 로컬 공간에서 인수·해시·접근 조건을 기록한다.

P01의 추가 감사 결과와도 대조했다. 이미 확보한 6,470행 자산 대장은 다시 요청하지 않는다. P01이 별도로 분류한 현장 RF 배선/포트·손실 자료는 U02, 설비 인터록·현장 한계는 아래 확장 단계에 해당한다. 실제 완료 시험건은 개발에 필요한 항목을 보존한 비식별 사본이나 허가된 기존 위치로 인수한다.

## 이후 전체 시험소로 확대할 때 필요한 내부 자료

다음은 지금 한꺼번에 제출할 목록이 아니다. 관련 기능을 시작할 때 현재 보유 자료와 실제 대상 범위를 먼저 확인한다.

| 시점 | 회사/현장만 제공할 수 있는 자료 | 용도 |
|---|---|---|
| 실제 시험 구역·물리 자동화 설계 전 | 실제 배치/동선 도면, 설치된 설비·RF 스위칭/배선 구성, 현장 인터록·비상정지·운전 제약과 점검 기록 | 설비 모델과 실제 공간·안전 조건 연결. 공개 장비 매뉴얼은 P01이 수집한다. |
| 내부 업무·보고/품질 절차 연결 전 | 사용 중인 의뢰/견적/시료관리/성적서 양식, 내부 승인·발행 역할, 실제 기관의 인정/지정 범위·검증된 방법·불확도 자료. 기존 SOP가 있으면 비교 자료로 인수 | 실제 업무 규칙과 보고서/품질 흐름 구현. 새 SOP를 사용자가 작성하는 것을 개발 선행조건으로 만들지 않는다. |

자료 제공은 장비 운전·시설 이동·외부 제출 권한을 부여하는 행위와 구별한다. 실제 작업 범위와 권한은 해당 연동 단계에서 확인한다.

## 공개 수집과 개발의 담당

P01은 [추가 수집 요청](2026-10-23-additional-collection.md)에 따라 공개 공식 문서와 미확보 원문 접근 경로를 조사하고, [Un-licensed 전체 catalog](../../virtual_profiles/README.md)의 정확 모델·세대·변형과 기존 자료를 먼저 대조한다. 개발1~4는 [전체 장비 가상화](../../handoff/development/VLAB-ALL-001.md)를 병렬 구현한다. 개발총괄이 자료 인수·우선순위·계약·통합 검증을 담당하며 사용자가 개별 에이전트에게 다시 지시할 필요는 없다.
