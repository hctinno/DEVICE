# 사용자가 직접 준비할 자료

작성일: 2026-10-23, Asia/Seoul. 공개 자료 추가 수집은 P01에 `DEV-EVIDENCE-20261023-002`로 요청했다. 이 문서는 공개 수집으로 확인할 수 없는 실제 제품·현장 정보와 회사가 가진 제한 자료만 정리한다.

현재 PDF 추출, 접수 작업자, 가상 시험 복구, 사용자 화면 개발은 계속 진행한다. 아래 자료는 해당 실장비 연동·비교 검증에 사용하며, 전체 자료가 모일 때까지 개발을 중단하지 않는다. 첫 실증은 스마트폰 2.4 GHz Wi-Fi b/g/n이고, 전체 시험소의 업무·물리 작업 무인화 목표는 유지한다.

## 먼저 준비할 최소 자료 — 첫 제품 1대와 시험 구성 1개

기존 파일이 있으면 접근 가능한 폴더 위치를 알려 주는 것으로 시작한다. 새 설명서나 정리표를 작성할 필요는 없다. 없는 자료는 미보유로 표시하고, 개발총괄이 필요한 세부 항목을 확인한다.

| 묶음 | 사용자가 제공할 최소 자료 | 공개 자료만으로 해결되지 않는 이유 / 사용 시점 |
|---|---|---|
| U01. 실제 시험용 스마트폰과 제조사 시험도구 | 첫 대상의 모델·변형, HW/FW 버전, 보유 제품 사양·안테나 구성·출력 설정 범위/tune-up 자료. 해당 기종의 RF 시험용 펌웨어·도구/API 설명서·설치/복구 절차와 허용된 사용 조건이 있으면 함께 제공 | 실제 대상과 OEM 제공 패키지의 호환성은 공개 일반 문서로 확정할 수 없다. 실제 DUT 어댑터와 시험모드 검증 전에 필요하다. 일반 ADB를 RF 시험도구로 대체하지 않는다. |
| U02. 실제 사용할 계측 구성과 교정 자료 | 우선 사용할 장비·센서의 모델/시리얼/옵션/FW가 있는 자산표 또는 명판·설정 화면 사진, 해당 교정성적서. 보유한 RF 연결도/사진, 케이블·감쇠기 구성과 해당 경로의 손실/보정 파일 | 수집한 모델 목록은 실제 설치·옵션·교정 상태를 입증하지 않는다. 현장에 N1914A/N9030A가 있다고 가정하지 않는다. 실제 연결 및 보정 계산을 검증하기 전에 필요하다. |
| U03. 기존 실제 시험 1건의 연결된 파일 묶음 | 가능하면 같은 제품/조건의 의뢰서·제품 첨부 → 실제 장비의 원시 파일·설정/완료 로그 → 적용 보정·계산 파일 → 최종 성적서. 이미 보유한 동일 시험건부터 제공 | 공개 성적서의 표는 원시 파일과 동일하지 않다. 데이터 파서·수치 추적·가상/실측 비교의 독립 검증에 사용한다. 해당 사례가 없으면 미보유로 두고 이후 권한이 정해진 실증에서 확보한다. 지금 새 측정을 수행하라는 요청은 아니다. |
| U04. 회사가 보유한 제한 원문·소프트웨어의 이용 위치 | 유료 규격 원문, 비공개 OEM 매뉴얼/도구를 이미 보유했다면 허용된 파일 경로나 열람 방법 및 사용 조건. 정확한 미확보 문서명·판본은 P01의 조사 결과로 좁힌다 | 공개 요약은 허가된 원문을 대체하지 않는다. 지금 일괄 구매하거나 비밀번호/라이선스 키를 전달할 필요는 없다. 필요한 원문 검토·해당 도구 연동 단계에 맞춰 확보한다. |

U01과 U02는 첫 실물 연동 대상을 확인하는 우선 입력이다. U03과 U04는 보유 여부부터 확인하며, 자료가 없는 동안 공개 근거와 합성 입력으로 가능한 구현·검증을 계속한다. 제한 원문과 실제 고객 자료는 공개 Git에 넣지 않고, 허용된 로컬 공간에서 인수·해시·접근 조건을 기록한다.

## 이후 전체 시험소로 확대할 때 필요한 내부 자료

다음은 지금 한꺼번에 제출할 목록이 아니다. 관련 기능을 시작할 때 현재 보유 자료와 실제 대상 범위를 먼저 확인한다.

| 시점 | 회사/현장만 제공할 수 있는 자료 | 용도 |
|---|---|---|
| 실제 시험 구역·물리 자동화 설계 전 | 실제 배치/동선 도면, 설치된 설비·RF 스위칭/배선 구성, 현장 인터록·비상정지·운전 제약과 점검 기록 | 설비 모델과 실제 공간·안전 조건 연결. 공개 장비 매뉴얼은 P01이 수집한다. |
| 내부 업무·보고/품질 절차 연결 전 | 사용 중인 의뢰/견적/시료관리/성적서 양식, 내부 승인·발행 역할, 실제 기관의 인정/지정 범위·검증된 방법·불확도 자료. 기존 SOP가 있으면 비교 자료로 인수 | 실제 업무 규칙과 보고서/품질 흐름 구현. 새 SOP를 사용자가 작성하는 것을 개발 선행조건으로 만들지 않는다. |

자료 제공은 장비 운전·시설 이동·외부 제출 권한을 부여하는 행위와 구별한다. 실제 작업 범위와 권한은 해당 연동 단계에서 확인한다.

## 공개 수집과 개발의 담당

P01은 [추가 수집 요청](2026-10-23-additional-collection.md)에 따라 공개 공식 문서와 미확보 원문 접근 경로를 조사하고, 실제로 사용자 입력이 필요한 항목만 근거와 함께 반환한다. 개발1~4는 [현재 개발 단위](../../handoff/development/SPRINT-001.md)를 이어 간다. 개발총괄이 두 결과를 연결하며 사용자가 개별 에이전트에게 다시 지시할 필요는 없다.
