# DEV-E3632A-READBACK-011 — 기존 자료의 설정/계측 경계 대조

2026-10-24 · Asia/Seoul. 총괄이 P01 한 창구에 실제 전달한 좁은 후속 요청이다. 다음 [가상 readback019](../superpowers/specs/2026-10-24-e3632a-virtual-readback-design.md)은 기존 PowerSupply의 공개 observation snapshot/measure를 재사용하며 지원하지 않는 read action은 추가하지 않는다. 전체 자료 수집 완료를 기다리지 않는다. P01이 v020/S05-B0005 한 명에게 실제 배정했고 task9037B/SHA `c4b569843cd62c8e458f0e2ee831ed0d6dcc2bf7be3cb31c669c2596bb27909a`를 인수했다. 수집자 ACK/동결 패킷은 수신 후 기록한다.

기존 CTRL008/S05-B0003·기존 공식 Guide와 원문 hash/경로/검토행을 먼저 재사용한다. 원문/프로그램 복사·중복 수집0을 우선하며 다음6~10근거 행만 요청했다.

1. 정확 source의 전압/전류 설정 질의와 setpoint/current limit의 의미.
2. OUTP 질의의 요청 enable와 실제 delivery·보호·실패 차이.
3. 전압/전류 MEAS 질의·반환 단위/OFF·오류/완료·신선도와 보장하지 않는 범위.
4. simulation return0·pass-only abort/disable·tracking getter 위험이 성공/출력OFF를 입증하지 않는 근거.
5. P15V/P30V programming 최대와 장비 정격·DUT 한계의 차이.
6. 두 기존 Agilent/H.P 프로필·exact 모델/계열/FW/옵션·원문/의존 권리·실물 미확인 관계.

정확 file/commit/line/hash·확보/미확인을 보존한다. core/transport·FW/옵션/정지 근거 공백은 unknown이다. 현재 원문이 없을 때만 필요한 공식 부분을 작게 구체화하고 예산/권리를 보고하도록 했다. 새 로그인/구매/비공개 SW·전체 driver/kernel·source 실행/설치·장비 discovery/출력은 요청하지 않았다. 원문/code body는 private이고 공개는 검수된 서지/hash/status뿐이다. 수집자 배정/검수는 P01이 유지한다. 사용자 추가 준비 요청0이다.
