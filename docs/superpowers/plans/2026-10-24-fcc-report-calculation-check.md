# 성적서 계산 연결 023 실행 계획

[설계](../specs/2026-10-24-fcc-report-calculation-check-design.md)에 따라 개발3이 신규3파일만 구현한다.

1. 완료019 branch/e3d5b69·원문 인수/실패/실제 조회 증거를 보존하고 새 전용 branch를 만든다.019 독립 코드 검토는 총괄이 별도로 진행한다.
2. 명료화한021 usage 전체와 기존 calculations.calculate를 읽고 입력6키·사용 claim/출처·정확 결과DTO·예산·고정 오류를 소유 usage에 먼저 고정한다. 총괄이 빠르게 대조한 뒤 missing-module·잘못된 근거/단위/판본 RED부터 실행한다.
3. 같은case의 검토된 문맥·페이지 근거/claim을 검증하고 기존 계산을 재사용한다. 재계산/원래 보고 수치/선언tolerance 비교/부족·미표현을 분리하고 입력·원문·실패를 보존한다. 코드·실측·법적 승인/새RF물리 엔진은 만들지 않는다.
4. 관련 검사와 준비된 첫 P01/021 private 실제 사례를 따로 실행한다. 자료 미확보로 실제 비교가 미실행이어도 합성 계약 검증·독립 가능한 개발을 계속한다. 소유3파일만 commit/push·원격 대조 후 SHA/증거·한계를 총괄에 보고한다.
5. 총괄 독립 리뷰/소유 수정→통합/회귀·문서/링크·게시 후 검토된 셋업과 기존 가상 흐름을 잇는 다음 작은 단위를 배정한다. 전체 수집 완료/원시 데이터/사용자 추가 준비를 선행조건으로 만들지 않는다.
