# VLAB-ALL-001 D2 계측 통신 소프트웨어 가상 역할

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. 기존 개발2 세션에서 직접 구현하며 하위 에이전트를 만들지 않는다.

**Goal:** Unlicensed 가상 시험소의 계측·통신·시험 소프트웨어와 보조 VNA를 상태와 입력에 따라 실행한다.

**Architecture:** 독립 역할 factory들이 JSON 가능한 포트 입력을 검사하고 가상 tick에 따라 취득·완료·취소·무효·복구를 처리한다. 물리 동작·네트워크 없이 명시적인 합성 정책으로만 값을 계산한다. 통합 runtime은 총괄/개발3의 소유다.

**Tech Stack:** Python 3.12 표준 라이브러리, unittest. 추가 의존성 없음.

**Spec:** [고정 설계](https://github.com/hctinno/DEVICE/blob/7b1d4e3ce5bbc1e2f43b1c127c0ee13a182f6645/docs/superpowers/specs/2026-10-23-whole-report-virtual-lab-design.md), [배정](https://github.com/hctinno/DEVICE/blob/7b1d4e3ce5bbc1e2f43b1c127c0ee13a182f6645/handoff/development/VLAB-ALL-001.md). 후속 총괄 결정으로 Unlicensed를 필수 gate로 한정하고 `network_analyzer`를 보조 케이블 검증 역할에 추가했다.

## Global Constraints

- 소유: `labflow/virtual_fleet/instruments.py`, `tests/test_virtual_fleet_instruments.py`, `docs/fcc/virtual_fleet_instruments_usage.md`, 이 계획.
- 기존 모듈·DB·하네스·UI·requirements 및 다른 담당의 `core.py`, `rf.py`, `facility.py`, `__init__.py`, catalog/integration을 수정하지 않는다.
- 원문·실측 수치/수식·시리얼·암호는 공개하지 않는다. 감사와 복호 사본은 비공개 `.local/SM-A176U-audit/`에 보존했다.
- 실장비·현장망·SDK/API·ADB·펌웨어·Office/한컴·매크로를 실행하지 않는다.
- RF `power_dbm`은 ON 구간 평균이다. `duty_cycle`은 `0 < d <= 1`, `crest_factor_db`는 ON 평균→peak 차이다. crest 누락은 명시적 CW 정책만 허용한다. 수동 RF 경로의 손실/이득은 upstream에서 한 번 반영한다.
- 센서 출력은 총괄이 고정한 measurement packet을 사용한다. 누락 power/측정량/유효성은 정상 0으로 바꾸지 않는다.
- catalog의 모든 적용 프로필을 역할 구현과 연결해 private 호환 검사를 수행한다. 이름만으로 제조사 옵션/FW/물리 정밀도를 주장하지 않는다.

## 고정 인터페이스

`DEVICE_FACTORIES[role](profile: dict, seed: int) -> device`

```python
perform(action: str, parameters: dict, *, tick: int, setup_revision: int, inputs: dict) -> dict
advance(*, tick: int, setup_revision: int, inputs: dict) -> None
observation(*, tick: int, setup_revision: int) -> dict
author_control(fault: str, value) -> None
```

`perform`은 `status`, `values`, `setup_changed`를 반환한다. `ROLE_ACTIONS`는 action별 `parameters`의 type/required/unit과 completion을 선언한다. `ROLE_PORTS`는 `{inputs:{port:kind}, outputs:{port:kind}}`다. runtime의 provenance를 입력에서 복사하거나 숨은 고장 설정을 관측에 노출하지 않는다.

## 역할과 포트

| 역할 | 입력 | 출력 |
|---|---|---|
| power_meter | sensor:measurement, power:power | measurement:measurement |
| signal_analyzer, emi_receiver | rf:rf, power:power | measurement:measurement |
| signal_generator | power:power | rf:rf |
| communication_tester, bluetooth_tester, wireless_ap | rf:rf, power:power | rf:rf, measurement:measurement, data:data |
| dfs_system | rf:rf, power:power | rf:rf, measurement:measurement |
| network_test_station | rf:rf, data:data, power:power | measurement:measurement, data:data |
| test_software | measurement:measurement, data:data | control:control, data:data |
| network_analyzer | reference:rf, test:rf, path:data, power:power | measurement:measurement |

필요한 입력은 action별로 구분한다. 양방향 RF/DFS 연결을 같은 DAG의 순환으로 만들지 않는다. VNA 단일점은 reference/test RF 차이, sweep은 명시적인 가상 path 주파수/손실 곡선으로 계산한다. 곡선 없는 주파수 sweep·위상·제조사 전체 VNA 명령은 지원으로 표시하지 않는다.
