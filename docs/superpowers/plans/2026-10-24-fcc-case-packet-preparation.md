# FCC 사례 packet 입력 준비035 실행 계획

[고정 설계](../specs/2026-10-24-fcc-case-packet-preparation-design.md)를 개발1이 전용 branch/소유3파일에서 수행한다. 총괄은 담당 구현을 대신하지 않는다.

1. f1500c1·부모021/028/030 source/usage와 미커밋 상태를 보존한다. 소유 usage에 정확 API/키/오류/예산·metadata 준비와 실제 검증의 차이를 먼저 적고 manifest/두 blob·범위·I/O0 RED를 실행한다.
2. 기존 data-only 검증을 공유하며 메모리 API를 구현한다. constructor의 기존 None/실제 source·literal/permission 처리와 오류를 보존한다.
3. 새 검사를 통과시키고 관련021/028/030·추출/접수 검사를 실행한다. 기존 producer 동일성·입력/반환 사본 독립·상한 정상 입력과 실패를 확인한다.
4. 총괄 동결 LG031 또는 S04 canonical JSON/index로 원문을 열지 않는 private replay를 실행한다. 실제 준비 JSON 검증과 PDF/권리·AI/물리 검증0을 분리한다.
5. 소유3파일 commit/push·원격SHA/원바이트 증거를 총괄에게 반환한다. 독립 지적은 소유 RED/수정 후 재검증하며 최종Yes 뒤 총괄이 통합·회귀·게시하고 다음 연결을 배정한다.
