# DEV3-SESSION-001 가상 세션 구현 계획

> **For agentic workers:** 이 계획은 superpowers:executing-plans로 같은 세션에서 직접 구현한다. 이번 배정은 추가 에이전트 생성을 금지한다.

**Goal:** 기존 VirtualLab의 합성 동작을 재시작 뒤 재현하고 요청 중복·파일 손상을 명시적으로 처리한다.
**Architecture:** seed/설정/순서 있는 입력과 결과를 JSON으로 저장하고 기존 VirtualLab에 재생한다. SHA-256과 재생 결과를 확인하며 OS 파일 잠금과 같은 디렉터리의 원자 교체를 사용한다. 숨은 제어는 별도 작성자 API로만 받고 관측 내보내기에서 제외한다.
**Tech Stack:** Python 3.12, 표준 라이브러리, 기존 VirtualLab, unittest.
**Spec:** [DEV-SPRINT-001](../../../handoff/development/SPRINT-001.md)의 DEV3-SESSION-001.
**시작 SHA:** 340231ef2950f8427ca994f1bab08cdd6a6aa0f9.

## 경계와 설계 선택

- 기존 핵심 모듈, CLI, DB, requirements, 루트 문서를 변경하지 않는다.
- 제품 코드는 `labflow/virtual_session.py`, 검사는 `tests/test_virtual_session.py`, 사용법은 `docs/fcc/virtual_session_usage.md`로 한정한다.
- 저장은 현재 모듈의 clone에 속한 `.local/` 아래로 제한한다. 파일에는 숨은 제어가 있으므로 AI에는 관측 투영만 전달한다.
- 내부 속성 snapshot은 기존 구현과 결합되므로 선택하지 않는다. pickle/코드 복원은 사용하지 않는다.
- 공개 API는 `VirtualSession.create/open(session_id, storage_root=...)`, `execute(request_id, action, **arguments)`, `scenario_control(...)`, `observations()`, `close()`와 context manager다.
- 입력 ID/종류/동작/JSON 내용이 같으면 저장된 결과를 반환한다. 같은 ID의 다른 내용은 거절하며 별도 동작으로 실행하지 않는다.
- 관측 동작은 configure_dut, set_path, start_tx, stop_tx, meter, advance만 허용한다. 숨은 제어는 inject_fault/set_path만 허용한다.
- 파일 버전, 엔진 소스 SHA, Python 주요/부 버전과 RNG 버전을 고정해 호환되지 않는 환경을 명시적으로 거절한다.
- 파일 저장 실패 뒤 객체는 더 이상 실행하지 않는다. 잠금을 닫고 마지막 커밋 파일을 다시 열어 요청 ID로 재시도한다. 미완료 임시 파일은 실패 증거로 남긴다.
- 저장된 관측의 SHA 검증과 실제 재생 검증은 무결성 검사다. 비밀 키 서명이나 공격자 인증이 아니며, 유효한 과거 파일 전체로 되돌리는 공격/삭제를 탐지하는 외부 기준은 없다.
- OS 잠금은 같은 저장 파일을 이용하는 작성자를 직렬화한다. 관측 API 분리는 파일·Python 객체에 직접 접근할 권한을 차단하는 보안 격리가 아니다.

## Review Focus

1. 완료 결과 재조회/중복 advance가 tick·난수·측정 ID를 바꾸지 않는지 확인한다.
2. 실행 중/중단/오류 큐 상태를 재생해 오래된 결과를 새 결과로 노출하지 않는지 확인한다.
3. 쓰기 전후 실패 모두 기존 파일 또는 완전한 새 파일로 복구하고 임시 증거를 보존하는지 확인한다.
4. 손상 JSON/중복 키/잘못된 버전/결과 변조/경로 탈출을 거절하며 원본을 덮지 않는지 확인한다.
5. 숨은 제어·설정·기대값이 관측에 섞이지 않고 다른 프로세스/스레드의 작성이 충돌하지 않는지 확인한다.
