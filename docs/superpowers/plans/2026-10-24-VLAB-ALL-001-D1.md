# VLAB ALL 001 개발1 RF 역할 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 사용자의 배정에 따라 하위 에이전트 없이 개발1이 직접 수행한다.

**Goal:** Un-licensed 전체 catalog의 DUT·센서·RF 경로 역할을 실제 설정/관측/고장/복구 상태로 실행한다.

**Architecture:** `rf.py`가 10개 role factory와 고정 장치 인터페이스, action/port 선언을 제공한다. 공통 runtime이 tick/revision·요청 중복·출처 envelope·DAG를 소유하고 RF 모듈은 가상 입력·설정으로만 출력과 유효성을 계산한다. 기존 단일 장비·접수·DB·UI는 수정하지 않는다.

**Tech Stack:** Python 3.12 표준 라이브러리, unittest. 외부 서비스·실장비·실제 원문 수치는 사용하지 않는다.

**Spec:** 총괄 고정 설계 `docs/superpowers/specs/2026-10-23-whole-report-virtual-lab-design.md`, 배정 `handoff/development/VLAB-ALL-001.md` 및 후속 공통 계약. 해당 문서는 총괄 복제본에서 읽었으며 이 분기에 임의 복사/병합하지 않는다.

## Global Constraints

- 전용 clone/브랜치의 시작 HEAD는 `64a8b36bc99cf6a39a8232bd2fcce735292fe0ce`다.
- 소유 파일은 `labflow/virtual_fleet/rf.py`, `tests/test_virtual_fleet_rf.py`, `docs/fcc/virtual_fleet_rf_usage.md`, 이 계획뿐이다.

## Review Focus

- bool/NaN/무한대/잘못된 단위·표·대역은 입력 단계에서 거절한다.
- 손실은 각 node에서 한 번 적용하며 분기 출력의 전력 보존과 센서 평균값을 확인한다.
- 취득 중 입력/셋업 변경과 고장 해제 뒤 이전 센서 값을 새 결과로 사용하지 않는다.
- controller-only와 실제 RF matrix·2/4way·fixed/step은 서로 다른 동작과 포트로 검증한다.
- 운영 관측에 작성자 고장 이름/값·정답이나 임의 upstream 필드를 노출하지 않는다.

## 독립 리뷰 RF-R1 후속 수정

총괄이 최초 커밋을 인수한 뒤 control 선택 되돌림에서 이전 pending 경로가 남는 결함을 보고했다. rf1 활성 → rf2 대기 → 완료 전 control을 rf1로 되돌린 조건에서 tick 5에 9 dBm 대신 19 dBm이 나오는 회귀 실패를 재현했다.

- [x] 회귀 검사를 먼저 추가해 `19.0 != 9` 실패를 확인했다.
- [x] upstream 선택이 현재 안정 경로와 같으면 pending 경로와 기존 due_tick을 취소하도록 최소 수정했다. 다시 rf2를 선택하면 새 settling 시각을 사용한다.
- [x] RF 40개, 전체 자기 분기 187개(22.255초), 담당 catalog 38개 정상·disconnect·복구 산술이 통과했다.
- [x] 최신 총괄 의존 파일과 수정 RF의 private 연결 preview 10개가 통과했다. snapshot은 `67db7ea2c91611b98ad01574029b84462991faa27999326ba1f166afd1f54a69`다. HTTP 검사가 추가돼 복제본에 server 파일을 포함했으며, 최초 누락 실패 로그도 보존했다.

동일 pending 선택을 반복해도 settling 시각을 연장하지 않는 기존 동작도 확인했다. 인터페이스·공통 모듈·실물 운전 범위는 변경하지 않았다. 후속 커밋과 원격 SHA는 총괄 인수 메시지로 추적한다.

추가 리뷰 경계도 회귀에 포함했다. controller가 rf1을 유지한 상태에서 matrix의 로컬 select_path(rf2)를 요청한 뒤 기다려도 controller의 rf1을 유지해야 한다. 공통 runtime의 동일 코드와 합성 DUT 10/20 dBm·손실 1 dB 연결에서 최초 구현은 19 dBm, R1 수정본은 9 dBm을 출력해 결함과 차단을 모두 확인했다. 추가 구현 변경 없이 단위 검사 1개를 보완했으며, RF 41개·전체 188개(20.326초)가 통과했다. 실제 catalog나 실장비 비교로 확대 해석하지 않는다.
