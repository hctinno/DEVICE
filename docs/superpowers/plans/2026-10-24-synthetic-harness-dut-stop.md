# DUT-STOP-HARNESS-016 실행 계획

[고정 설계](../specs/2026-10-24-synthetic-harness-dut-stop-design.md)를 따른다.013의 독립 No/RED/소유 수정·최종 실제 증거를 먼저 보존하고 인수한다.

1. 최종013 의존 SHA·기존 fixture/harness 의미와 정확 Fleet 결합·신규3파일 소유권을 ACK하고 별도 branch에서 usage/DTO/고정 오류·실행/포장 예산을 동결한다.
2. 누락 모듈 RED 뒤 고정 기존 fixture 하네스와 단일 후속 합성 stop의 coordinator를 구현한다. 기존 stop/cleanup 의미와 policy를 변경하지 않는다.
3. 정상/예산 종료/실패·gate/불확정·identity/목표·원문/자식 기록·bytes/depth·동시/반복·무I/O와 관련 회귀를 확인한다. 실제 기존 Fleet→fixture harness→013의 새 증거는 double와 분리한다.
4. 원본·실패/전후 SHA·문서검사를 보존하고 소유3파일 commit/push/원격 SHA를 인계한다. 독립 지적은 owner fix하고 총괄 인수/회귀/게시·다음 단위로 이어간다.
