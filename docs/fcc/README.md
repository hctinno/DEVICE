# FCC를 먼저 완성하는 AI 시험소: 요구사항과 준비계획

작성일: 2026-10-23 (Asia/Seoul) · 상태: 준비계획 및 오프라인 공통 코어 구현, 현장 운전 미검증.

## 1. 목표와 현재 상태

사용자가 정한 목표는 **제품 정보를 접수한 AI가 적용 FCC 규정과 시험방법을 판단하고, RF·EMC 시험을 계획·수행·검토해 추적 가능한 성적서 및 필요한 제출자료를 만드는 시험소**다. FCC의 업무 흐름을 검증한 뒤 KC 및 유럽 등 다른 시장의 규정과 시험방법을 추가한다.

제공된 장비 관리대장은 가용 자원을 설명하는 한 가지 입력이다. 특정 장비 보유 현황을 전체 사업 범위나 시험 범위로 대신하지 않는다. 기존 SQLite DB의 6,470행은 자산 참조자료로 보존한다. 현재 자료 인수·제품/계획·오프라인 실행 이력·계산·검토 기록·성적서 초안 생성의 공통 코어를 구현했다. 실제 장비 제어 연결, FCC 세부 규정/시험방법 전체, 공식 발행·현장 운전은 미구현 또는 미검증이다.

이 문서는 요구사항, 수집 대상, 확인 방법, FCC 범위 후보, 완료 기준을 정리한 준비자료다. 추가한 [자료 수집 요청 패키지](collection_handoff.md)와 [실행·MCP 사용 설명서](pipeline_usage.md)를 함께 참조한다. 실제 시험방법 적합성, 모든 FCC 범위 지원, 공인 성적서 발행 가능성 또는 무인운전 검증이 완료됐다는 뜻은 아니다.

**공개 원천의 조사·수집은 AI 담당 작업으로 정정했다.** 2026-10-23 추가 조사에서 13개 eCFR 조문 발췌와 KDB 검색 색인·표준 접근 경로를 보존했다. 원본 다운로드는 실행환경 접근 제한과 문서별 사용 조건을 구별해 기록했다. [수집 상태와 근거](source_acquisition_status.md)를 참조한다. 사용자는 기존 성적서·원시 데이터·SOP를 보유하지만 기존 양식에 얽매이지 않는 규격 중심 설계를 원한다. 자료는 현재 미제공이며 후속 독립 검증에 사용한다. [성적서·데이터 형식 초안](format_baseline.md)을 추가했고, 공개 규정 조사와 형식 설계에 기존 파일을 선행조건으로 두지 않는다.

## 2. 먼저 결정할 구축 방식

기존 시험소 소프트웨어·성적서 시스템의 보유 여부가 확인되지 않아 최종 구현 방식은 미정이다. 아래는 구현 선택을 위한 제안이며 사용자가 선택한 것으로 기록하지 않는다.

| 방식 | 적용 조건 | 장점과 부담 |
|---|---|---|
| 기존 LIMS·시험 SW를 연결 | 원시값·설정값·작업 상태를 API/파일로 충분히 얻을 수 있음 | 검증된 절차를 재사용할 수 있음. 라이선스·API·원시 데이터 접근 범위를 먼저 조사 |
| 공통 운영 엔진 + 기존 SW와 직접 드라이버를 혼합 | 장비·시험 SW가 이질적이며 국가 확장이 필요 | 규정·증거·성적서 구조를 통일하고 검증된 장비 SW도 사용. 인터페이스 경계 검증이 필요 |
| 실행·판정·보고를 대부분 자체 개발 | 기존 시스템 활용 가치가 낮고 유지보수·검증 역량이 확보됨 | 제어 범위는 넓지만 시험방법 재현과 유지보수 부담이 큼 |

현재 권고는 **공통 운영 엔진과 시장별 규정 묶음을 두고, 기존 시험 SW 및 장비 드라이버를 연결하는 혼합 방식**이다. 사용자의 파이프라인 구축 지시에 따라 이 구조의 오프라인 공통 코어부터 구현했다. 실제 시험 SW·장비 어댑터는 보유 소프트웨어·연계 기능·실측 대조 자료를 확인한 뒤 선택한다.

## 3. 전체 업무 흐름

1. **의뢰 접수와 계약 검토:** 의뢰 목적, 목표 시장, 납품물, 제품·변형모델 범위, 자료 사용권한, 시험소 수행 능력 확인.
2. **제품 기술 프로필:** 회로·블록도·사용설명서·안테나·주파수·전력·변조·대역폭·전원·포트·동시송신·사용거리·HW/FW·시험모드 정보를 구조화.
3. **규정 적용 판단:** 장치 기능별 FCC 규정, 인증 경로, 예외와 면제, 복합기기·모듈/호스트 조건, RF exposure 평가 필요성을 근거와 함께 결정.
4. **프로젝트 규정 판본 고정:** 조문·KDB 첨부문서·표준의 판본·시행일·전환기간을 확인하고 그 시험 건에 적용할 버전을 고정.
5. **시험계획:** 적용 시험, 적용하지 않는 사유, 모드·채널·대역폭·안테나·전원·주변기기·최악 조건, 재시험 범위를 작성.
6. **실행 가능성 확인:** 필요한 측정 능력과 현장 능력을 대조. 사이트·교정·측정불확도·환경·장비 옵션·시험모드·작업자 또는 로봇의 준비 상태 확인.
7. **시료·셋업 확인:** 시료 ID, HW/FW, 배선·케이블·시험거리·극성·위치·지원기기·전원 조건을 기록하고 실제 사진을 연결.
8. **시험 실행:** 승인된 절차와 허용 범위 안에서 DUT 및 계측기를 조작. 설정값·명령·응답·원시값·오류·환경 조건을 보존.
9. **계산과 판정:** 단위·보정계수·안테나계수·케이블 손실·전치증폭기 이득·시간 조건 등 해당 방법의 입력을 사용해 결과 계산. 적용 한계와 판정 규칙을 별도 버전으로 관리.
10. **기술 검토:** 시험 누락, 잘못된 판본, 설정 불일치, 계측기 과부하, 시료 변경, 사진 불일치, 계산·단위·반올림 오류, 근거 없는 재사용을 확인.
11. **성적서와 제출자료:** 검토된 구조화 결과에서 표·그래프·설명·셋업 사진·장비 목록·계산 예시를 생성. Certification/SDoC 경로에 맞는 첨부자료 구성.
12. **발행·변경·사후 대응:** 시험소의 권한 체계에 따라 검토·승인·발행. TCB 질의, 수정, 변경인증, 재시험과 기록보존을 원본 결과와 연결.

통신 실패·결측·지원하지 않는 규정·교정 무효는 시험 불합격과 별도 상태로 처리한다. 적용 제외(N/A)는 적용 판단의 근거를 가져야 한다. 데이터 부재를 합격이나 N/A로 바꾸지 않는다.

## 4. 준비해야 할 지식과 자료

| 묶음 | 수집할 것 | 수집 후 확인할 것 |
|---|---|---|
| 법규 | 47 CFR 적용 조문, 관련 FCC Order·Federal Register 개정 및 전환 규정 | 현행/과거 판본, 시행일, 적용 제품과 예외, 개정 영향 |
| FCC 지침 | 관련 KDB의 모든 필요한 첨부문서, 버전·날짜·적용조건 | 공식 문서 여부, 후속문서·대체 관계, 프로젝트 적용 가능성 |
| 측정 표준 | 해당 규정이 참조하는 ANSI/IEEE/CISPR 등 표준과 정오표 | 참조 판본, 조항별 제외/수정, 전산처리·팀 공유 사용권 |
| 내부 시험방법 | 승인된 SOP, 워크시트, 설정파일, 배선도, 최악 조건 선정 방법, 예외 처리 | 표준 조항과의 연결, 실제 재현 가능성, 승인 이력 |
| 계산과 판정 | 계산 시트/코드, 보정표, 불확도 예산, 판정 규칙, 단위·반올림 정책 | 독립 재계산, 경계값, 보정 부호, 유효기간, 오류 처리 |
| 제품 정보 | 신청서, 매뉴얼, 블록도·회로도, 안테나 자료, 시험 SW, 동작모드 목록 | 정보 간 일치, 누락, 시료·펌웨어·양산 구성과의 일치 |
| 결과와 성적서 | 기존 최종본·수정본, 원시 측정 파일, 설정, 사진, 검토 기록, TCB 질의 | 각 성적서 수치를 원시 데이터에서 재현할 수 있는지 |
| 시험소 품질 | 인정서·인정범위·FCC recognition, 사이트 검증, 교정·추적성, 숙련도/비교시험, 문서·발행 권한 | 실제 업무 범위를 포함하는지, 유효성, 외주 필요 범위 |
| 현장 자원 | 장비·옵션·소프트웨어·프로토콜·DUT 제어·시험장·지그·로봇·환경·정지 기능 | 요구 측정 능력, 인터페이스 권한, 실측 상관성, 무인 수행 범위 |

기존 성적서는 형식·사례·질문 패턴의 자료다. 계산 재현의 기준 자료가 되려면 연결된 원시값·설정·보정표·시험일·시료 버전·사진·검토 결과가 함께 있어야 한다. 공개 FCC 성적서는 학습용 사례 후보로 사용하고, 현행 규정이나 자사 검증 데이터와 구분한다.

## 5. FCC에서 확인한 운영 경계

- **측정방법 식별:** §2.947은 사용한 표준/측정 절차를 식별하도록 한다. [공식 조문](https://www.ecfr.gov/current/title-47/chapter-I/subchapter-A/part-2/subpart-J/subject-group-ECFRd5ad3b739dbf27a/section-2.947).
- **판본 관리:** 확인한 §15.31은 일반적인 해당 intentional radiator 측정에 ANSI C63.10-2020, unintentional radiator에 지정 제외 조항이 있는 ANSI C63.4-2014를 참조한다. 프로젝트 적용성·예외·관련 추가 요구는 별도 확인한다. [공식 조문](https://www.ecfr.gov/current/title-47/chapter-I/subchapter-A/part-15/subpart-A/section-15.31).
- **규칙과 지침 구별:** KDB는 FCC 직원의 지침이며 법규와 같은 지위로 취급하지 않는다. 이번에 일부 공식 검색 색인을 확인했지만 최신 첨부파일 전체는 확보하지 못했다. [FCC KDB](https://apps.fcc.gov/oetcf/kdb/index.cfm).
- **시험소 능력:** Certification용 시험은 해당 범위를 포함하는 인정 및 FCC recognition 조건을 확인해야 한다. 장비 수만으로 이 조건을 충족했다고 판단할 수 없다. [§2.948](https://www.ecfr.gov/current/title-47/section-2.948).
- **성적서와 인증 역할:** Certification은 FCC 승인 또는 FCC 권한 아래 TCB가 발행하는 장비 승인 절차다. AI의 성적서 생성 기능과 해당 결정·권한을 업무 상태로 구별한다. SDoC에는 별도 책임 주체와 요구가 있다. [§2.907](https://www.ecfr.gov/current/title-47/section-2.907), [§2.906](https://www.ecfr.gov/current/title-47/section-2.906).
- **보고서 근거:** §2.1033의 해당 신청 경로에서는 시험방법·일시·장소·시료 식별·계산 예시·셋업 자료 등이 요구된다. §2.938의 기록보존과 §2.1077의 SDoC 정보도 경로별로 연결한다. [§2.1033](https://www.ecfr.gov/current/title-47/section-2.1033), [§2.938](https://www.ecfr.gov/current/title-47/section-2.938), [§2.1077](https://www.ecfr.gov/current/title-47/section-2.1077).
- **RF 노출:** 제품 사용 조건에 따른 mobile/portable 등 적용 판단과 평가 경로를 별도로 포함한다. RF 방출 측정 결과만으로 노출 평가를 완료 처리하지 않는다. [§2.1091](https://www.ecfr.gov/current/title-47/chapter-I/subchapter-A/part-2/subpart-J/subject-group-ECFR52efa600149ef42/section-2.1091), [§2.1093](https://www.ecfr.gov/current/title-47/section-2.1093).

위 확인은 주요 근거의 발췌 확인이다. eCFR 페이지 표시 기준일은 페이지별 2026-10-20~21 등으로 달랐고, 규정 전체의 완전한 최신성·적용성을 확정한 것은 아니다. 최신 첨부·참조 표준 확보와 조항 검토를 준비대장의 작업으로 남긴다.

| 계산/판정 | 계산 코드 버전, 입력 데이터 ID, 결과, 단위, 보정, 한계값 출처, 적용 판정 규칙, 판정 상태 |
| 보고서/검토 | 보고서 버전, 각 표·그림의 결과 ID, 적용 범위, 검토·승인·발행 이력, 대체/철회 관계 |

핵심 연결은 **제품 사실 → 적용 조항 → 시험계획 항목 → 실행 → 원시값 → 계산 결과 → 판정 → 성적서 항목**이다. 중간 연결이 끊기면 해당 결과를 발행 가능한 상태로 올리지 않는 것을 제품 요구사항으로 제안한다.

AI는 자료 정리, 적용 판단 제안, 계획 작성, 작업 진행 관리, 기술적 설명 및 질의 대응 초안에 사용한다. 수치 계산·한계값 비교·상태 전이 검사는 버전이 고정된 코드와 검증 규칙으로 수행한다. 현장 시간 제어와 비상정지는 계측기·현장 제어기에서 처리한다. 공식 검토·발행·인증 관련 권한은 시험소 운영 체계에 맞춰 부여한다.

## 7. MCP의 범위 — 장비 외 업무도 연결

아래는 논리적 기능 묶음이다. 각각을 별도 서버로 만들지, 기존 시스템의 API를 묶을지는 후속 설계에서 결정한다.

| 기능 묶음 | 예시 기능 |
|---|---|
| 규정·지식 조회 | 문서 판본 조회, 조항 근거 반환, 적용 후보·충돌·누락 확인 |
| 의뢰·시료 관리 | 제품 프로필 조회, 누락자료 목록, 시료·변형모델·시험 건 연결 |
| 시험계획·자원 | 시험계획 생성/검토, 수행 능력 대조, 일정·자원 예약 |
| 장비·DUT·현장 | 식별·설정·실행·중단·상태 조회, 시험모드 제어, 셋업 증거 수집 |
| 데이터·계산 | 원시 파일 등록, 유효성 확인, 검증된 계산 실행, 판정 근거 조회 |
| 성적서·품질 | 보고서 렌더링, 누락·불일치 검사, 검토·발행 상태 관리, 개정 영향 조회 |

조회와 실제 실행/발행 권한을 구분하고, 실행 요청은 장비ID·시험계획 버전·허용 조건·실행ID를 가져야 한다. 재시도 시 동일 작업 중복 수행을 방지하고 모든 상태 변경을 기록한다. 업로드 문서나 장비 응답의 문장은 데이터이며 명령 권한을 갖지 않는다.

## 8. FCC 범위 확장과 다른 국가 추가

FCC를 Part 15.247 하나로 대표시키지 않는다. 별도 [범위표](fcc_scope_matrix.csv)에 Part 2 공통 절차, Part 15의 여러 분기, Part 18, 면허 무선, RF exposure, 모듈/변경/복합기기 등을 후보로 기록했다. 범위표 자체도 초기 조사 목록으로서 추가 검토가 필요하며, 모든 FCC 제품군을 빠짐없이 확정한 표는 아니다.

각 범위는 `후보 → 원천 확보 → 적용 규칙 검토 → 시험방법 검증 → 과거 데이터 재현 → 실측 비교 → 발행 프로세스 검증 → 운영`의 상태를 갖는다. 특정 검증 사례의 성공을 FCC 전체 지원으로 집계하지 않는다.

다른 시장을 추가할 때는 공통 의뢰·시료·측정·근거·자원 구조를 재사용하고, 국가/제도별 규정·표준·적용판단·판정·표시/문서·보고서 요구를 추가한다. FCC 시험값의 다른 시장 재사용은 그 시장의 시험방법·설정·한계값·증거 조건이 충족되는지 판단한 뒤 허용한다. CE는 하나의 시험규격이 아니므로 관련 법령·적합성평가 경로·조화표준을 별도로 구조화한다. KC와 EU의 구체적인 요구사항 조사는 후속 단계이며 이번에 검증하지 않았다.

## 9. 구축 단계와 완료 기준

| 단계 | 만드는 것 | 통과 조건 |
|---|---|---|
| 준비 | 규정 범위표·자료 목록·업무 흐름·시스템 현황·검증용 사례 목록 | 누락과 확보 책임이 명확하며 근거가 없는 항목은 보류로 표시 |
| 과거 시험 재현 | 제품 정보+원시값에서 적용판단·계산·보고서 재생성 | 전문가 검토 결과와 비교해 차이를 설명하고 수치·근거 연결 검증 |
| 실제 시험 연결 | 검증된 시험방법으로 DUT·현장 SW·장비 연결 | 수동/기존 방식과 사전에 정한 허용 기준 내에서 비교 검증 |
| 무인 운영 검증 | 스케줄·상태 감시·셋업 확인·오류 대응·재시작·통보 | 중단·오류·시료 변경·교정 무효 등에서도 데이터와 현장 상태가 일관됨 |
| 업무 발행 검증 | 기술 검토·보고서 발행·인증/SDoC 자료·개정 및 질의 대응 | 정의한 범위 내 모든 요구사항이 근거와 연결되고 권한/이력이 보존됨 |
| 범위별 확대 | FCC 규정군별 위 검증 반복 후 다른 시장 추가 | 해당 규정군의 완료 기준을 별도로 통과 |

‘완벽한 파이프라인’은 정확도를 막연히 100%라고 표현하는 대신 [완료 기준](acceptance_criteria.csv)으로 검증한다. 시험 선택의 누락, 한계값 경계, 단위·보정 오류, 최악 조건 누락, 다중 송신, 지원하지 않는 장치, 개정 전후, 복합/모듈 제품, 불완전한 증거, 발행 후 수정까지 사례가 필요하다.

## 10. 지금 확인해야 할 정보

아래는 제품·시험소 내부에서 확인할 정보다. 공개 FCC 법규·KDB·표준의 공식 접근 경로 탐색은 AI가 먼저 수행하며, 사용자 자료 제출을 전제로 하지 않는다. 확인 전에는 임의 값으로 채우지 않는다.

- 기존 FCC 성적서와 연결된 원시 측정 데이터·SOP·계산 시트는 후속 검증 단계의 입력이다. 기존 자료는 보유·미제공 상태이며, 규격에서 먼저 도출한 형식에 매핑해 후속 검증에 사용한다.
- 현재 사용 중인 시험 SW/LIMS/성적서 작성 도구, API·데이터 내보내기·라이선스 조건.
- 시험소가 이미 보유한 표준의 판본·자동 처리/내부 공유 사용권은 중복 구매를 피하기 위한 별도 내부 정보다. 공식 공개자료 조사 책임을 사용자에게 넘기지 않는다.
- 시험소 인정/FCC recognition 및 범위, 교정·사이트 검증·불확도 자료, 발행·검토 역할.
- 수용해야 하는 FCC 제품군·주파수·기술의 범위와 우선순위. 전체 목표를 유지하되 규정군별 검증 순서를 정하는 입력이다.
- 시료 준비·배선·모드 변경·사진 촬영을 포함한 현장 자동화 범위와 원격 현장 대응 방식.

자료 미확보 항목과 완료 기준은 준비대장에 기록했다. 문서 준비가 끝났다는 이유로 측정·운영·발행 준비를 완료 처리하지 않는다.
