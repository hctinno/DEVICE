# 수집3(S03) — FCC SAR·인체노출 규정·시험방법

상태: 역할·이름 확정. 실제 로컬 준비와 실행 여부는 별도 확인. [공통 지시](../AGENT_PROMPT.md)와 [시작 안내](START_HERE.md)를 먼저 따른다. 작성 경로는 자기 `.local/collection/s03/`뿐이며 Git을 사용하지 않는다.

SAR와 관련 RF 노출 평가의 적용/제외 조건, 한계, 표준·KDB 첨부, 측정·검증·보고 요구를 수집한다. 사용자는 RF·EMC·SAR를 1차 목표로 확인했다. b/g/n 완료를 기다리지 않고 SAR 작업열을 병렬 진행한다.

첫 작업열은 스마트폰 휴대 사용과 Wi-Fi의 노출 평가 연결 근거다. 이후 head/body 등 사용 위치, 거리·액세서리, 동시 송신, 출력 제어/시간 평균과 관련 시험조건을 공식 근거에 따라 확장한다. MPE·전력밀도·HAC는 SAR와 구별해 적용성을 기록하며 전부 필수라고 가정하지 않는다. OTA 성능 인증 전체는 자동 포함하지 않는다.

반환할 내용:

- 법령·KDB 모든 필요한 첨부·허용 표준 판본·전환/대체 관계.
- 안테나/송신 조합·출력 목표·사용 조건 등 필요한 제품 입력과 적용 판단 출처.
- DUT 위치, 스캔·후처리, 매질/프로브/시스템 검증, 동시 송신, 불확도·보고 항목의 근거 위치.
- 실제 DUT/시스템 정보 없이는 결정할 수 없는 조건과 내부 자료 요청 목록.

제조사 SAR 시스템·SW·프로브·팬텀 문서는 S05, DUT 도구는 S07, 공통 품질·보고 요구는 S08을 참조한다. 수집 단계에서 시스템 유효성이나 제품의 SAR 적합을 판정하지 않는다.

진행·막힌 항목·완료 결과는 메인(P01)에 보고한다. 메인이 사용자 질문과 추가 배정을 취합하며, 다른 수집자에게 직접 재배정하거나 다른 폴더를 수정하지 않는다.
