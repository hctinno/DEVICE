# 세션 8 — 원시 데이터·성적서·품질

상태: DRAFT, 미착수. [공통 지시](../AGENT_PROMPT.md)와 [실행 전제](README.md)를 먼저 따른다. 작성 경로는 자기 `.local/collection/s08/`뿐이며 Git을 사용하지 않는다.

FCC RF/EMC/SAR 보고 요구, 공개 시험건, 추적성·교정·불확도·시험기관 인정·검토/발행 요건의 공식 근거를 수집한다. 기존 성적서 양식의 복제를 목표로 삼지 않는다. 새 DB·원시 데이터/성적서 형식과 검증 코드는 현재 클라우드 담당이 설계한다.

반환할 내용:

- 필수 보고 항목·조항/판본·측정 원본·설정·보정·단위·판정·불확도·시료/장비 식별의 출처 색인.
- 같은 FCC ID/모델에 연결되는 공개 RF·EMC·SAR 성적서, 사진, 운영 설명·첨부 목록의 연결 관계.
- 공식 요구/공개 사례의 관행/수집자 제안을 구별한 필드 후보. 보고서 그래프와 실제 계측기 원시 파일을 구별.
- 교정 유효성·추적성·환경/사이트 검증·검토/발행 권한·보존/변경 이력의 요구 및 실제 현장 증거 요청 목록.

개별 시험방법의 원본은 S01~S03, 장비/시스템의 내보내기·제조사 교정 절차는 S04/S05를 참조한다. 실제 교정서·완료 시험건·원시 데이터는 현장 보유 자료로 요청하며 인터넷 사례로 대체하지 않는다.

P01이 배정·해시·형식·게시를 맡고, S08은 품질 요구를 조사한다. S08이 모든 배치의 출시 승인자나 최종 기술 판정자가 되는 것은 아니다. 공통 STATUS나 다른 세션 결과는 수정하지 않는다.
