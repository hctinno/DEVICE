# 세션 7 — DUT·제조사 시험 도구·공통 SW

상태: DRAFT, 미착수. [공통 지시](../AGENT_PROMPT.md)와 [실행 전제](README.md)를 먼저 따른다. 작성 경로는 자기 `.local/collection/s07/`뿐이며 Git을 사용하지 않는다.

제조사 RF 시험 펌웨어/도구, ADB·CLI·SDK·API·GUI, 시험 SW와 공통 VISA/IVI/MCP 연동의 공개 공식 문서·예제를 수집한다. 실제 내부 패키지는 제공자·버전·접근 조건·필요 파일을 요청 명세로 남긴다.

첫 작업열은 스마트폰 b/g/n 송신 모드 진입·설정/조회·종료·오류/재접속·RF 상태 확인에 필요한 기능이다. 채널·대역폭·변조/속도·송신 체인·출력 목표·패킷/듀티·튜너 상태 등은 도구 지원과 공식 근거를 구별해 기록한다.

반환할 내용:

- 제품/칩셋/OS·시험 FW·도구/드라이버·권한·라이선스·설치/접속 조건의 호환 관계.
- 호출/응답/오류·상태 조회·완료 확인·로그/원본 내보내기와 문서 위치.
- 지원 기능/미지원/미확인, GUI 조작만 가능한 기능, 자동화 가능성의 근거와 실제 검증에 필요한 입력.
- 제조사에 받을 패키지·문서·예제·라이선스/계정 조건의 목록. 비밀키나 고객 자료는 공개 반환하지 않음.

Android 가상 에뮬레이터, 실제 RF 신호를 만드는 네트워크/기지국 시뮬레이터, 원격 PC 조작 도구를 구별한다. ADB 연결이나 원격 화면 접근을 RF 시험모드 확보로 간주하지 않는다. “Anywhere”는 정확한 제조사·제품명 미확인 항목으로 남기며 다른 도구로 단정하지 않는다.

SAR 전용 SW는 S05, 통신시험기 자체의 명령 매뉴얼은 S04가 원본을 소유한다. 도구 설치·펌웨어 플래싱·키 획득·DUT/계측기 제어는 수행하지 않는다.
