# 수집1(S01) — 기존 수집 세션 / FCC RF 규정·시험방법

상태: 역할 확정. **처음부터 자료를 수집하던 기존 세션을 그대로 사용한다.** [공통 지시](../AGENT_PROMPT.md)와 [시작 안내](START_HERE.md)를 따른다. 새 결과의 작성 경로는 자기 `.local/collection/s01/`이며 Git을 사용하지 않는다. 기존 폴더와 진행 중 다운로드는 보존하고 legacy 인계로 등록한다.

먼저 현재 확보·진행·미착수 요청과 원본 위치를 자기 `legacy-inventory`에 기록해 P01에 제공한다. 기존 EMC/SAR/장비 자료도 유지하며 이미 진행 중인 다른 분야 요청은 예약해 마무리한다. 신규 배정부터 FCC RF에 집중하고, 기존 자료를 새 역할에 맞추려고 다시 받거나 이동·삭제하지 않는다. 파일 작성 중에는 배치가 동결됐다고 보고하지 않는다.

FCC RF의 법령·KDB와 관련 첨부·채택/허용 표준·전환/대체 관계를 수집한다. 공통 FCC 법령 원문은 기본적으로 S01이 소유하고 분야별 적용 색인은 S02/S03/S08이 참조한다. 개별 KDB·표준 담당은 고정 배정표를 우선한다.

첫 작업열은 [b/g/n 우선 자료](../WIFI24_BGN_FIRST_BATCH.md)의 §15.247 및 관련 방법이다. 이후 다른 FCC RF 기능별 후보를 확장하되 실제 제품의 지원 기능을 추정하지 않는다. SAR과 EMC 분야 원문을 중복 소유하지 않는다.

반환할 내용:

- 원문과 모든 필요한 첨부, 판본·효력/전환일·초안/확정 구별, 관련 문서 연결.
- 제품 입력 → 적용 조건 → 시험항목 → 방법/조건 → 필수 기록의 출처 색인. 각각 조항·페이지·표를 연결.
- 안테나 이득, 송신 체인, 대역폭/모드, 출력 목표·튜너 상태 등 확인에 필요한 입력과 조건의 공식 근거.
- 확보·접근 제한·미확인·후속 조사 목록. 최신 발행판과 FCC 사용 가능 판본을 별도로 기록.

시험방법 실행 코드·규칙 승인·장비 동작은 수행하지 않는다. 필요한 계측기 매뉴얼은 S04, 경로 문서는 S06, DUT 인터페이스는 S07의 원본 ID로 참조한다.
