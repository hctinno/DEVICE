# 수집6(S06) — 설비·모션·RF 경로

상태: 역할·이름 확정. 실제 로컬 준비와 실행 여부는 별도 확인. [공통 지시](../AGENT_PROMPT.md)와 [시작 안내](START_HERE.md)를 먼저 따른다. 작성 경로는 자기 `.local/collection/s06/`뿐이며 Git을 사용하지 않는다.

FCC RF/EMC/SAR를 수행하는 데 필요한 배정된 챔버·마스트·턴테이블·모션 제어기·RF 스위칭·전원·경로 제어·인터록·환경 감시 문서를 수집한다. 환경/신뢰성 시험장비 전체를 이번 범위로 추가하지 않는다.

첫 작업열은 전도 출력의 RF 경로와 상태 확인 근거, 이후 방사 측정의 위치/편파/각도 제어 및 인터록이다. HCT 자체 제작 또는 현장 통합 장비는 공개 문서의 한계를 기록하고 회로/배선/인터페이스/설정 자료 요청을 구체화한다.

반환할 내용:

- 정확한 모델·제어기·프로토콜·명령/API·위치/상태 피드백·통신 구성·버전 조건.
- 홈/원점, 이동 한계, 단위·좌표·속도, 완료/정지/비상정지, 인터록/접점과 오류 후 상태 확인 근거.
- 스위치 경로·포트/손실·허용 전력·전환 조건, 케이블/지그/전원 연결과 필요한 현장 확인 항목.
- 현재 배치·실제 주소·경로별 보정·센서/인터록 검증의 미제공 목록.

일반 RF 수동부품 모델 문서는 S04, SAR 전용 로봇/시스템 문서는 S05 원본을 참조한다. 실제 현장 주소 검색·네트워크 스캔·장비 출력/이동은 수행하지 않는다.

진행·막힌 항목·완료 결과는 메인(P01)에 보고한다. 메인이 사용자 질문과 추가 배정을 취합하며, 다른 수집자에게 직접 재배정하거나 다른 폴더를 수정하지 않는다.
