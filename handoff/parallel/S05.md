# 수집5(S05) — SAR 측정 시스템·전용 부품

상태: 역할·이름 확정. 실제 로컬 준비와 실행 여부는 별도 확인. [공통 지시](../AGENT_PROMPT.md)와 [시작 안내](START_HERE.md)를 먼저 따른다. 작성 경로는 자기 `.local/collection/s05/`뿐이며 Git을 사용하지 않는다.

배정된 SAR 시스템·전용 로봇/제어기·프로브/DAQ·팬텀·검증 다이폴/소스·조직 모사액·유전특성 측정 장비와 전용 SW의 제조사 자료를 수집한다. 이름에 SAR/phantom이 있어도 의료 선량·OTA용일 수 있으므로 모델과 용도를 확인한다.

반환할 내용:

- 시스템 구성·호환성·SW/모듈/API·옵션·펌웨어·라이선스와 제조사 매뉴얼.
- 위치·스캔 계획·좌표/단위·측정 상태·완료/오류·정지·원시 데이터/프로젝트 내보내기 인터페이스.
- 프로브/DAQ 교정 데이터의 파일 구조·적용 조건, 팬텀·액체 특성·온도, 시스템 점검/검증 절차의 원문 위치.
- 실제 보유 구성·프로브 교정서·시스템 점검 결과 등 현장에서 받아야 할 입력 목록.

SAR 시스템 전용 로봇·컨트롤러·SW 원본은 S05가 소유하고 S06/S07이 참조한다. 범용 독립 로봇/시설 장비로 별도 배정된 모델은 S06 소유이며 고정 배정표가 우선한다. 규제 시험요건은 S03, 공통 추적성/불확도/보고 요구는 S08을 참조한다.

매뉴얼 확보와 API 사용권·설치·실측 검증을 구별한다. SAR 로봇 이동, 교정 실행, DUT RF 출력, 설치 프로그램은 실행하지 않는다.

진행·막힌 항목·완료 결과는 메인(P01)에 보고한다. 메인이 사용자 질문과 추가 배정을 취합하며, 다른 수집자에게 직접 재배정하거나 다른 폴더를 수정하지 않는다.
