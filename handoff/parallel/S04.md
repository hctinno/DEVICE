# 세션 4 — RF·EMC 계측기와 일반 RF 부품

상태: DRAFT, 미착수. [공통 지시](../AGENT_PROMPT.md)와 [실행 전제](README.md)를 먼저 따른다. 작성 경로는 자기 `.local/collection/s04/`뿐이며 Git을 사용하지 않는다.

배정된 RF/EMC 분석기·EMI 수신기·전력계/연결 센서·신호원·통신시험기 및 일반 안테나·LISN·감쇠기·커플러·필터 등의 모델 문서를 수집한다. 대장의 분류명만으로 이번 범위나 제어 가능성을 확정하지 않는다.

첫 작업열은 2.4 GHz 전도 출력에 필요한 분석기/전력계 후보와 그 옵션·센서·명령이다. 정확한 현장 모델 선정은 아직 입력 사항이며 “N90”을 임의 모델로 확정하지 않는다. 이어 방사·AC 자원 문서를 수집한다.

모델별 반환할 내용:

- 제조사·정확한 모델/suffix·문서 적용 범위, 조작/설치·프로그래밍·통신·성능검증/교정 문서.
- 장치 식별, 설정/조회, 완료 동기화, 오류, 정지/복구, 트레이스·원본 전송의 공식 명령/API 위치.
- 지원 옵션·펌웨어·드라이버·라이선스 조건, 입력 한계·워밍업·지원 인터페이스.
- 직접 제어/별도 제어기/GUI/수동 부품/미확인 구분. 수동 부품은 사양·사용 조건·보정/교정 요구를 기록.

공통 매뉴얼은 여러 모델과 연결하되 서로 다른 모델 ID를 임의 병합하지 않는다. SAR 전용 시스템/부품은 S05, 경로 제어기는 S06, 범용 통신 SDK는 S07이 소유한다. 명령·드라이버·예제는 실행하지 않는다.
