- catalog는 보고서 사용행 218개와 DUT/보조 근거를 연결한 **64프로필/24역할**이다. 64대의 실제 자산이나 모든 제조사 기능의 구현 수가 아니다. 전도 예제는 11개 연결 노드와 나머지 53개 목록 노드를 함께 배치한다.

## 동작과 리뷰

장비 구성→시작/취득→가상 tick→완료/무효→복구를 실제 역할 모델로 실행한다. 전원·환경·RF·센서·결과가 선언된 포트로 전달되며 연결된 상류의 미출력은 하류의 미연결로 숨기지 않는다. 셋업 변경은 이전 측정을 무효화하고 재취득을 요구한다. 운영자 요청과 작성자 고장 주입을 분리하며 화면에는 고장 정답이나 비공개 원문·경로·암호를 전달하지 않는다.

독립 리뷰에서 발견한 다음 중요 결함을 수정하고 실제 재현 사례를 재검토했다.

- 현미경의 로컬 시료가 연결된 상류를 덮는 문제, 작성자 제어 예외 후 재시도 중복, 후속 전파 중 바뀐 revision의 수치 반환: 입력 우선·격리·불확실 결과 캐시·무효화로 수정했다.
- RF 제어기를 원래 경로로 되돌려도 이전 전환이 완료되거나 로컬 명령이 제어기 선택을 우회하는 문제: 대기 전환 취소와 제어기 우선으로 수정했다.
- 분석기의 미지원 field strength 수용과 송신 on/off 후 이전 측정 유지: 구성을 바꾸지 않는 거절과 revision/취득 무효화로 수정했다. 첫 송신 이후 RF 유지도 확인했다.
- 직렬화 불가능한 Unicode 응답이 성공 캐시에 남는 문제: UTF-8 직렬화를 먼저 확인하고 안전한 불확실 응답·같은 요청 ID 재시도를 적용했다.

공통/시설·RF·계측·화면과 총괄 wrapper/CLI의 최종 재검토에서 해당 검토 범위의 잔여 Critical/Important는 없었다. 이 판정은 아래 합성 검증 범위를 넘지 않는다.

## 남은 연결

이 구현은 합성 계산·장비 상태·연결·운영 화면 검증이다. 제조사 전체 명령/옵션/FW, 실제 계측 정확도·교정·불확도, FCC 전체 시험방법, 실장비/현장 업무와 전체 물리 무인화 검증은 미실행이다. 실제 모델 AI의 운전/학습·평가를 완료한 것으로 표시하지 않는다.

다음 단위는 이 런타임을 기존 관측 전용 AI 하네스·가상 세션/증거 보존·접수 흐름에 연결하고 지원한 시나리오별 성공/실패/복구 평가를 확대하는 것이다. 실제 모델 공급자와 현장 설정은 해당 연동 전에 확인한다. P01에서 확정한 모델별 원문 묶음은 준비되는 대로 해시·판본을 대조해 인수하며 수집 전체 완료를 기다리지 않는다. 원본/복호문/암호·사용자 측정값과 private intake는 공개 Git에 넣지 않는다.
