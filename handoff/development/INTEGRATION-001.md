## 총괄 복제본 검증

- 전체 Python 회귀: `.venv/Scripts/python.exe -B -m unittest discover -s tests`로 235개, 74.082초, 모두 통과. 개발2의 최종 33개와 공통 시각 회귀 7개가 포함된다.
- PDF 추출기 최종 40개, 가상 환경/세션 51개, 공통 현재 시각 7개를 별도로 통과했다. 서로 다른 실행의 수를 전체 검사 수에 합산하지 않는다.
- Node 상태/응답 계약 20개 통과. 브라우저 수용 9개와 리뷰 회귀 10개도 통합 소스로 통과했다.
- 브라우저 검증은 한 검사 프로세스 안에서 합성/빈 저장소용 loopback 서버를 열고 종료 시 닫았다. 초기 별도 백그라운드 서버 기동 명령이 정책에 거절된 뒤 그 방식을 사용하지 않았다. 최종 소스 해시·로그·화면은 `.local/ui-browser-integration/5d499d1cf3c8/receipt.json`과 해당 하위 폴더에 있다. 데스크톱 화면도 직접 확인했다.
- 합성 파일 접수 → 별도 제공자 프로세스 → 분석 저장 → HTTP 조회 연결을 실제 실행했다. 제품·EU 시장·fixture 표시·원본 해시·알림 1건과 재실행 시 0건 인수를 확인했다. 기록은 `.local/integration-worker-ui/d2ca712b91a4/receipt.json`이다.
- 변경 Python 9개 AST, JavaScript 구문과 `pip check`, Git 공백 검사는 통과했다. 루트 문서 8개/로컬 링크 141개와 변경된 하위 Markdown 12개/링크 39개의 UTF-8·문자·링크 검사도 통과했다.
