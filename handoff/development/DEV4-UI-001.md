# DEV4-UI-001 — 첫 접수 운영 화면

배정일: 2026-10-23, Asia/Seoul. 담당: 개발4. 통합·공통 계약 검토: 총괄.

## 목적과 범위

사용자가 개발4를 만들어 프론트엔드를 맡기도록 지시했다. 기존 [사용자 흐름 설계](../../docs/superpowers/specs/2026-10-23-smartphone-wifi24-bgn-design.md), [화면 규칙](../../DESIGN.md), [접수 사용법](../../docs/fcc/active_intake_usage.md)을 적용해 현장 PC의 브라우저에서 접수 내용을 확인하는 첫 실행 가능한 화면을 만든다. 연결 확인 뒤 이 작업의 구현을 시작하며 세션 준비만으로 종료하지 않는다.

첫 단위는 접수 목록 → 의뢰 상세 → 사실/출처·누락/충돌 질문 → 알림/작업 상태의 조회다. 화면의 상태는 현재 Python 접수 서비스에서 얻으며 하드코딩한 성공률·가짜 AI 응답을 쓰지 않는다. 빈 자료, 분석 대기, 실패, 보류, 근거 부족을 각각 표현한다. 합성 예시 데이터로 먼저 재현 가능하게 검증하고 합성 표시를 유지한다.

업로드·대화 답변·가상 실행 제어는 이후 연결할 전체 화면 흐름으로 설계하되, 이 단위에 포함하지 않은 기능은 사용할 수 있는 것처럼 보이게 하지 않는다. 실제 모델 작업자·실장비 연결·공식 성적서 발행도 완료로 표시하지 않는다. 첫 화면의 조회 기능을 완성한 뒤 총괄에게 통합 계약과 다음 단위를 제안한다.

## 소유권과 연결 경계

- 개발4 전용 독립 clone과 `codex/dev4-frontend-20261023`에서만 변경한다. 총괄은 실제 경로·시작 SHA를 세션에 전달한다.
- `frontend/` 아래 화면 코드·자체 빌드 설정·프론트엔드 검증, `docs/fcc/frontend_usage.md`, 작업 전용 설계/계획 문서를 소유한다.
- Python 연결이 필요하면 신규 `labflow/ui_read_model.py`, `labflow/ui_server.py`와 전용 테스트로 격리할 수 있다. 기존 `active_intake.intake_status`와 `intake_jobs.notifications`의 실제 계약을 먼저 확인한다. 초기 서버는 로컬 루프백에서 조회만 제공하고 임의 파일 경로나 데이터 변경 요청을 받지 않는다.
- 공통 `schema.sql`, `store.py`, 기존 접수/작업자/가상 시험 모듈, `labflow/__main__.py`, 공통 의존성 파일은 임의로 변경하지 않는다. 필요한 변경은 총괄에게 파일·필드·이유와 함께 제안한다. 기존 제품 규칙·화면 기준은 변경하지 않는다.
- 기능 구현에 맞는 기술 선택은 개발4가 정하고 근거·실행법을 기록한다. 이미 승인된 흐름 안의 통상적인 구현 선택은 진행하고, 전체 제품 동작이나 공통 계약을 바꾸는 결정은 총괄에게 모은다.
- 수집 자료는 총괄에게 요청한다. P01·수집1~8·다른 개발 채팅에 직접 지시하거나 새 세션을 만들지 않는다. 공유 수집 폴더와 다른 개발 clone에 쓰지 않는다.

## 완료 증거

1. 빈 상태와 합성 접수 상태를 실제 브라우저에서 열어 주요 동선·한국어·상태 배지·근거 표시를 확인한다. 합성 데이터를 실제 AI 분석·실측으로 표시하지 않는다.
2. 실제 서비스 응답과 화면 데이터 연결을 검증한다. 미지원 상태·누락 근거·원문 내 HTML/스크립트 문자열을 안전하게 표시하고 로딩/오류를 구별한다.
3. 변경한 연결 코드의 의미 있는 검사와 사용한 프론트엔드 빌드/검사를 실행한다. 접근 가능한 로컬 URL, 명령, 합성 입력 준비법을 남긴다. 전체 기존 테스트를 중복 반복하지 않되 공통 영향이 있으면 관련 회귀 검사를 수행한다.
4. 문서 변경 후 `python scripts/check_artifacts.py`와 추가 문서의 UTF-8·로컬 링크를 확인한다. 기능 검증과 문서 검증 결과를 구분한다.
5. 자신의 브랜치에 커밋·푸시하고 총괄에게 SHA, 파일 목록, 실행 화면/경로, 실제 검사 결과, 미구현 범위·필요한 공통 계약을 보고한다. 통합 브랜치 반영은 총괄이 담당한다.
