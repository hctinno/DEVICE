# DGM LabControl 구축 계약

2026-11-04. 대상은 `../samsung-rf/research/fcc-2026/manifest.json`의 확보 성적서입니다. 실물 주소·RF 경로·교정값은 사용자가 후속 제공하며 이번 작업은 라이브러리 구축입니다.

## 완료 기준

1. 확보 PDF의 장비표·지원장비에서 제조사/모델/분류/근거 페이지를 추출하고 누락 범위를 표시합니다.
2. 능동 장비는 공식 프로그래밍 문서·SDK와 실제 명령을 대조합니다. 수동 RF 부품을 제어 장비로 부풀리지 않습니다.
3. 근거가 있는 인터페이스에는 실제 VISA/TCP/serial 전송, 식별, 설정, 측정, 데이터 수집, 종료 API와 사용 예제를 구현합니다.
4. 모델 오인, 잘못된 인수, 응답 오류, 타임아웃, 중도 취소, 종료 실패를 검사합니다. localhost 통신 검수와 실제 장비 검수를 구분합니다.
5. 모든 장비의 지원 상태·빠진 옵션/라이선스·현장 설정 항목을 표로 내고 문서/테스트를 통과한 뒤 Git에 저장합니다.

## 범위와 제약

공개되지 않은 스마트폰 제조사 시험 프로토콜과 독점 SAR 시스템 API를 창작하지 않습니다. 지원 드라이버가 없으면 그 장비는 명확히 차단합니다. 동일 제조사라는 이유로 SCPI를 전용하지 않습니다. 실물 연결 전에는 '현장 즉시 가동 검증 완료'로 표시하지 않습니다. 드라이버 설치 후 주소/옵션/배선/교정 프로파일을 넣어 사용할 수 있는 코드가 목표입니다.
