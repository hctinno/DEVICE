# 작업 기준

이 폴더는 신규 Python 라이브러리입니다. 이번 대화에서 조사한 공개 APK의 정적 분석을 입력 자료로 사용합니다. 기존 앱·서버·업무 샘플은 사용하지 않습니다.

명령 숫자를 추정해 실행 가능 목록에 넣지 않습니다. 근거 파일과 줄 번호를 보존합니다. APK 설치·실행, 휴대폰 연결·송신, 보정값 쓰기는 이 개발 검수에 포함하지 않습니다.

검수: python -m unittest discover -s tests -v
생성: python scripts/build_catalog.py
산출물 UTF-8 및 깨진 한글 검사 필수. 생성 카탈로그 수동 수정 금지.
