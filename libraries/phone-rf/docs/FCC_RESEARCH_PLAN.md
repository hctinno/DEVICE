# 최신 폴더블 FCC 시험 재현 조사

기준일: 2026-11-04. 대상: Galaxy Z Fold8 미국 SM-F971U (A3LSMF971U), iPhone Duo 미국 A3447 (BCG-E9188A). 모델 연결은 제조사·통신사 자료와 FCC 기록을 대조합니다.

## 목표와 완료 기준

공개 FCC 제출 성적서를 로컬에 확보하고, 무선 기술별 시험항목·숫자 조건·DUT 제어 경로를 원문 페이지에 연결합니다. 기존 단말 제어 라이브러리에 기계판독 가능한 시험 계획과 준비 상태 검사를 추가합니다. 명령 미공개 항목은 필요한 제조사 자료와 차단 이유를 구체적으로 남깁니다.

1. 모델/FCC ID, 보고서 식별자, URL, 원문 SHA-256, 페이지 수를 기록합니다.
2. WLAN·Bluetooth·셀룰러·NFC·UWB와 추가 무선 기능, RF 노출·HAC 등 별도 시험을 구분합니다.
3. 설정값과 시작/종료·응답 근거가 모두 확보된 경우에만 실행 가능으로 분류합니다. 다른 모델의 명령은 호환성 미확인 후보입니다.
4. 재사용 가능한 다운로드/추출·검증 스크립트, JSON/CSV/한국어 분석 문서, 오프라인 테스트를 저장합니다.
5. 기존 테스트와 신규 검사를 통과한 뒤 작업 브랜치에 커밋하고 원격 SHA를 확인합니다.

## 검증 및 위험

PDF 해시·FCC ID·페이지 근거, 숫자 조건, 명령 근거 상태를 자동 검사합니다. 잘못된 모델·명령 누락·부분 조건에서는 실물 실행 계획을 만들 수 없어야 합니다. 성적서의 시험 실시 사실은 제어 프로토콜 공개 또는 현재 판매 펌웨어 호환성의 증거가 아닙니다. 공개되지 않은 숫자나 보정값을 추정하지 않습니다.

실폰·계측기·차폐실은 현재 연결하지 않습니다. 이번 합격 기준은 자료 확보와 소프트웨어 검수이며, 실측 재현 또는 FCC 적합 판정 완료를 의미하지 않습니다. PDF 원본은 로컬 캐시에 보관하고 재확보용 URL·해시를 버전 관리합니다.
