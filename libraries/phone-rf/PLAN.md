# DGM RF Command Library

목표: 단말 스마트폰 FCC 시험 자동화에서 재사용할 명령 카탈로그와 Python 제어 라이브러리. 범위는 WLAN, Bluetooth/BR/EDR/BLE, 셀룰러, NFC, UWB입니다.

완료 기준: 출처·숫자 인수·응답·전제조건·종료 명령·검증 상태를 기록하고, 검색/내보내기/명령 생성/통신/실패 처리 API를 제공합니다. 미확인 명령은 실행 가능 명령과 구분합니다. 실기기 없이 통과한 검사를 실기기 검증으로 표시하지 않습니다.

진행표: 자료 추출 30%, 카탈로그 25%, 제어 API 25%, 검수·문서 20%. 시작 0%. 예상 35~55분.

- [x] 확보한 최신 공개 APK의 RF 관련 분기 추출 및 원문 연결
- [x] 5개 무선 계열 카탈로그·숫자표·미확인 사항 생성
- [x] Python API·직렬 통신·모의 통신·시험 시퀀스 구현
- [x] 오류 응답·취소·타임아웃·종료 실패 검수: 자동검사 24개 통과
- [x] 사용 예제·검증 결과·배포용 ZIP 확인. wheel 독립 import와 211개 카탈로그 로딩 통과.

v0.1.0 당시: 211개 카탈로그, 숫자표 154행, 6GHz 채널표 118행. 실폰·계측기 검수 미수행. 아래 v0.2.0 보강 결과가 현재 상태입니다.

주요 한계: 모델/CSC/펌웨어·직렬 포트·계측기 모델이 미지정입니다. RF 설정이 곧 FCC 측정/합격 판정은 아닙니다. 미확인 셀룰러 명령을 타 제조사 문법으로 채우지 않습니다.

검증 도구: Python 표준 unittest, 소스 매핑 일치 검사, CLI 모의 실행, UTF-8 검사. 실폰·계측기 검사는 별도로 남깁니다.

## 2026-11-04 하위 RF 명령 보강

목표: 셀룰러 TX·NFC·UWB를 하위 실행 함수까지 추적하고 확인된 숫자 인수와 시작/종료 쌍을 구현합니다.

- [x] UWB S918NKSU1AWC8의 periodic TX, 채널, 안테나, 간격/패킷 수, 종료를 AT 시퀀스로 구현
- [x] NFC 16 PRBS 서비스 ID 31/32와 숫자 변환을 별도 서비스 API로 구현. AT 문법으로 오인하지 않도록 구분
- [x] 셀룰러 TX 추가 조사 수행. 인수/종료 근거 미확보로 실행 항목 추가 0개. 요청 전체는 미완료
- [x] 고정 빌드 제한, 잘못된 인수, 실패/취소 종료, 비동기 NFC 응답 한계 검사: 38개 테스트, CLI 4개 통과
- [x] v0.2.0 wheel 독립 import: 220개 AT, NFC payload 생성, 데이터 포함 확인. 배포 ZIP CRC·UTF-8 검사 통과

주요 위험: 서로 다른 빌드의 파서/서비스 조합, 출력 코드와 dBm의 혼동, 방송 전달을 RF 성공으로 오인하는 문제입니다. 실기기 없이 이를 검증됐다고 표시하지 않습니다.

현재 보강분: UWB AT 9개 추가로 전체 AT 카탈로그 220개, 별도 NFC 서비스 명령 2개. 실폰·RF 계측 검수 0건. NFC TECH/RATE 물리 이름, UWB 최신 빌드·출력 환산·시간 단위, 셀룰러 TX 전체는 미확인입니다.

검수 이력: 최초 wheel import 검사를 빌드 완료 전에 실행해 `ModuleNotFoundError: No module named 'dgm_rf'`가 발생했습니다. 빌드 exit 0 확인 후 동일 검사를 다시 실행해 PASS를 확인했습니다.
