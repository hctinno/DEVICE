# 보정·기준 비교 실행 계약

목표: WLAN 및 Bluetooth/LTE/NFC/UWB 설비 스캔에 주파수·경로·편파별 안테나 팩터, 케이블/스위치 손실, 선택 외부 전치증폭기 이득을 적용합니다. 보정 전계강도 최대 위치로 복귀하고, 모든 주파수 bin의 선언된 시험 기준 비교·최악 여유·판정 결과를 기록합니다. 실제 교정/기준 값은 사용자가 제공하며 가상 예제는 실제 규격으로 전환하지 않습니다.

초기 15%, 예상 60–90분. 주요 위험은 보정 부호/단위, 중복 보정, 교정 범위 밖 외삽, 만료/미래 교정, 경로·편파 누락, peak bin만 비교해 놓치는 초과, 검파기/거리/대역폭 불일치, 취소/cleanup 실패 뒤 잘못된 PASS입니다.

소프트웨어 구현·검수 완료. 실제 교정/기준·현장 RF/거리/검파기 검증은 미수행입니다. 배포 중 발견한 설치기의 0.6.0 고정값을 0.7.0으로 수정하고 카탈로그 버전은 pyproject.toml에서 생성하도록 변경했습니다. 새 venv 오프라인 설치와 설치본 README를 다시 검증했습니다. 원격 공유 기준은 이 변경이 포함된 main 커밋이며 최종 원격 SHA는 전송 후 확인합니다.

설계: 별도 evaluation JSON을 받아 기존 plan schema와 CLI를 유지합니다. 공통 correction engine은 50Ω 수신기 입력 dBm을 dBµV로 변환한 뒤 dB/m 전계 안테나 팩터와 손실을 더하고 외부 이득을 뺍니다. 각 trace bin에 적용하고 correction/evaluation 스냅샷과 canonical SHA-256을 저장합니다. 선형 Hz 또는 log-Hz 보간만 명시적으로 지원하며 외삽하지 않습니다. 자기장/근접장 임피던스 변환·자동 거리 환산은 지원하지 않습니다.

판정은 사용자 선언 기준과의 PASS/FAIL/INDETERMINATE/NOT_EVALUATED 비교이며 FCC 인증 판정이 아닙니다. 현재 swept analyzer의 POS 조건만 판정 가능하고 QP/average/RMS 방법은 NOT_EVALUATED로 구분합니다. 조건·기준 범위 불일치는 PASS를 금지합니다. 전체 실행·최대 복귀·cleanup 완료 후에만 최종 비교를 발행합니다. 실패/취소는 부분 비교 데이터를 보존하되 전체 판정은 NOT_EVALUATED입니다.

검증 기준: 50Ω 환산과 부호, frequency/polarization/path 보간, 보정으로 바뀌는 최대 위치/주파수, 최대 전계강도와 최악 margin 분리, 한계 경계·중복/누락 구간, 불확도 경계, 교정 유효기간·원문 설정·hash, 미일치/미확인 조건, 기존 raw workflow 회귀, WLAN/radio 가상·native mock·CLI·wheel·오프라인·README 재현, 원격 main SHA 대조. 실제 장비는 연결하지 않습니다.
