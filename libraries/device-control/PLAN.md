# DGM DeviceControl 구축 계약

최신 확장: SDK 0.7.0 [보정·기준 비교 계약](CORRECTION_PLAN.md), [입력/실행/제한](CORRECTIONS.md). 아래 수치는 버전별 과거 기록이며 최신 검수는 docs/validation.json을 따릅니다.

최신 확장: SDK 0.6.0의 [다중 무선 설비 스캔 계약](RADIO_SCAN_PLAN.md). 네 radio의 모션/RF 경로/최대 복귀와 가상·조건부 실장비 실행을 제공합니다. 아래 0.5.0 기록은 고정 경로 단계입니다.

현재 확장: SDK v0.5.0의 [다중 무선 실행 계약](MULTIRADIO_PLAN.md), [사용법/미확인 범위](MULTIRADIO.md). 기존 WLAN 가상/실장비 경로는 유지합니다. 아래 33개 검사·3종 simulator 수치는 v0.1.0 완료 기록입니다. 최신 검사 수치는 [validation.json](docs/validation.json)을 따릅니다.

목표: 다른 개발자와 사용자가 같은 설치·조회·프로파일·연결·수명주기 방식으로 장비, 모션/시설, 스마트폰 제어를 사용할 수 있는 재사용 SDK를 만듭니다. 제조사 공식 매뉴얼 기반 구현과 DGM 자체 API를 구별합니다. 제조사가 인증한 SDK라고 표시하지 않습니다.

완료 기준: 설치 패키지의 지원 목록/출처/작업 시그니처, 16 설비 드라이버와 OEM AT 연결, 프로파일 생성·오프라인 검사·환경 진단, 전원/모션/스마트폰 3종 모의 실행, 오류·취소·종료 검사, 새 설치에서 같은 명령 재현, GitHub 인계입니다. 실제 통신·RF/기계 검증은 이번 작업에 포함하지 않습니다.

초기 구현 진척 0%, 예상 30–60분. 이는 SDK 구축 작업의 추정이며 전체 시험소 진행률이 아닙니다. 위험: 범용 stop의 의미 차이, 모의값의 실측 오인, SDK 설치와 실제 firmware 준비 혼동, 부족한 프로파일의 실장비 접속, 기존 드라이버 동작 변경. 기존 드라이버는 재사용하고 어댑터 계층·설치/실패 테스트로 검증합니다.

구현/소프트웨어 검수 완료: 21개 지원 설명(실행 backend 17개, 참조/차단 4개), hardware template 17개, simulator 3개. 설치/동작 범위와 실물 검증 상태를 분리합니다. 실제 DUT firmware·물리 RF/기계·교정·FCC 시험은 미검증입니다. 상세 [검수 기록](docs/VALIDATION.md)과 [배포 manifest](docs/distribution-validation.json)를 확인합니다.
